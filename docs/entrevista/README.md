# Perguntas de entrevista, por fase

Três perguntas e respostas para cada fase do projeto, em primeira pessoa, para eu treinar a explicar o que fiz e por quê. As respostas usam só fatos deste repositório; onde existe número, ele vem de uma execução registrada.

> Rascunho escrito a partir do repositório. Antes de usar em uma entrevista real, releia e ajuste com as suas palavras. Onde a pergunta pedir experiência pessoal (por exemplo, "já trabalhou com CRM?"), **este material não responde por mim**: essa parte é minha e está marcada no [README da raiz](../../README.md).
